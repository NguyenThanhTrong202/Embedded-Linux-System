#Embedded Linux Systems

This repository contains Embedded Linux coursework
ARM Cortex-A9 using QEMU.

#Development Environment

- Host OS: Ubuntu Linux
- Target Architecture: ARMv7-A
- Target CPU: Cortex-A9
- Emulator: QEMU vexpress-a9
- Cross Compiler: arm-linux-gnueabihf-

## Projects

### LAB 01
Build an Embedded Linux system using:
- Linux Kernel 5.15
- U-Boot 2022.04
- BusyBox 1.35.0
- Initramfs
- QEMU

### LAB 02
Linux Device Driver and File Systems:
- Character Device Driver
- procfs and sysfs
- MTD and JFFS2
- BusyBox Init

### Assignment 01
How to Write a Device Driver:
- ioctl Interface
- Misc Counter Device
