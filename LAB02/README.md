# LAB 02 - Embedded Linux Systems

## Target
- Architecture: ARMv7-A
- CPU: Cortex-A9
- Machine: QEMU vexpress-a9
- Kernel: Linux 5.15

## Lab objectives
1. Character Device Driver
2. procfs and sysfs
3. MTD and JFFS2
4. BusyBox Init Integration

## Base system
The LAB02 root filesystem is based on the successfully
booted LAB01 BusyBox initramfs.
