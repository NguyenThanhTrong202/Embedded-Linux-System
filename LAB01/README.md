# LAB 01 - Building Embedded Linux

## Objectives
- Configure and build Linux Kernel for ARMv7
- Configure and build U-Boot
- Build BusyBox
- Create root filesystem
- Boot Linux on QEMU vexpress-a9

## Target Platform
- CPU: ARM Cortex-A9
- Architecture: ARMv7-A
- Linux Kernel: 5.15
- Emulator: QEMU
